# Как подключиться (одна команда)

Синхронизация пробела между двумя компами. Запустите **на обоих**.

## macOS

Открой **Terminal** и вставь:

```sh
curl -fsSL https://raw.githubusercontent.com/MaxPer2005/FWatch/main/install.sh | bash
```

При первом запуске macOS попросит разрешение **Accessibility** (это нужно, чтобы
ловить нажатие пробела). Открой:
*System Settings → Privacy & Security → Accessibility* → включи **Terminal** →
запусти команду ещё раз.

## Windows

Открой **PowerShell** и вставь:

```powershell
irm https://raw.githubusercontent.com/MaxPer2005/FWatch/main/install.ps1 | iex
```

Готово — работает сразу.

---

## Что происходит

Команда скачивает маленькую программу и подключается к общему серверу
`91.228.153.31:9000`. Когда один нажимает пробел — у другого нажимается пробел.

- Закрыть: закрой окно терминала (Ctrl+C).
- Запустить снова позже:
  - macOS: `~/.local/bin/sync client 91.228.153.31 9000`
  - Windows: `%LOCALAPPDATA%\FWatch\sync.exe client 91.228.153.31 9000`
- Связь сама переподключается при обрывах и не отваливается в простое.

## Если не работает
- **macOS «не видит нажатия»** — не выдано разрешение Accessibility (см. выше).
- **«нет связи / переподключение»** — проверь интернет; программа сама
  переподключится, как только сеть появится.
